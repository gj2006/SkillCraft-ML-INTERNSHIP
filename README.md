# SkillCraft Technology - Machine Learning Task 1

## House Price Prediction using Linear Regression

### Project Overview

This project uses a Linear Regression model to predict house prices based on selected housing features.

### Dataset

The project uses the House Prices dataset from Kaggle.

### Features Used

* GrLivArea
* BedroomAbvGr
* FullBath

### Model

Linear Regression

### Evaluation

The model is evaluated using:

* Mean Absolute Error (MAE)
* Mean Squared Error (MSE)
* Root Mean Squared Error (RMSE)
* R-squared (R²)

### Files

* `SCT_ML_Task1_House_Price_Prediction.ipynb` — notebook containing the code and analysis.
* `submission.csv` — predicted house prices.

### Tools and Libraries

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn
